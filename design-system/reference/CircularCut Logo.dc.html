The seed blade

One solid shape: a 12-tooth saw blade whose teeth curl like a seed head. It’s a tool and a growing thing at once. No rings, no ticks, no strokes, so it reads the same on a crate, in a README and in a browser tab.

Anatomy
12Hooked teeth. Each tooth rises on a convex curve and falls back into a soft gullet, so the blade reads as a saw and as a seed head.
−10°The blade is rotated −10° so it never sits perfectly square, like the rest of the UI.
Ø 14A hub cut-out with a 2.6-unit seed dot: the one detail that keeps it readable at 16px.
BlobThe container circle is drawn by hand: the radius varies within ±4%, so it reads as stamped, not compass-drawn.
Clear space

Keep a clear margin of at least the hub diameter on every side.

Minimum size

Mark: 24px. Lockup: 28px mark height. Tile: 16px.

Don’t

Don’t outline the blade, add strokes, gradients or shadows, use a perfect-circle container, sharpen the teeth, or recolour outside forest, lime and white.
