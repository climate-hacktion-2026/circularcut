# Submission checklist

Submit through the Junction platform by **9:00pm AEDT, Sun 4 Oct 2026**. Submit
progressively — don't wait until the last minutes, uploads can fail under load.

## Required fields

- [ ] Project name and one-sentence summary
- [ ] Selected challenge / COP31 track(s)
- [ ] Team nationality (Australia / New Zealand / Pacific Islands)
- [ ] Team members and roles
- [ ] Problem and target users
- [ ] Solution description and intended impact
- [ ] Project description / pitch (problem, solution, approach)
- [ ] Demo video — ≤2 minutes, recorded during the hackathon weekend
- [ ] Link to this public repository
- [ ] Any supporting material
- [ ] Tools used — outside tools, datasets, APIs, AI tools (→ [DISCLOSURES.md](DISCLOSURES.md))
- [ ] Confirm: no prior work, built at the event only

## Quality check before hitting submit

- [ ] All links open without requesting access
- [ ] Demo focuses on problem, working solution, and evidence it works
- [ ] Repo contains enough for a judge to understand and review it
- [ ] All team members listed correctly
- [ ] Submission saved and visibly marked complete
